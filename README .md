# PKMKPI Website

A responsive informational website for the **Pambansang Kapisanan ng mga May Kapansanan ng Pilipinas, Inc. (PKMKPI)**.

The website presents information about the organization, its strategic goals, disability classifications, community involvement, support opportunities, and development team.

## Features

- Responsive desktop, tablet, and mobile layouts
- Separate homepage and Our Team page
- Sticky responsive navigation bar
- Mobile navigation menu
- PKMKPI organizational information
- AEIOU strategic goals
- Guide to ten disability classifications
- Team member profiles
- Support and contact sections
- Accessibility controls
- High-contrast mode
- Adjustable text size
- Reduced-animation option

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

How to Run the Project
Download or clone this repository.
Open the project folder in Visual Studio Code.
Open index.html in your browser.

Alternatively, use the Live Server extension:

Install Live Server in Visual Studio Code.
Right-click index.html.
Select Open with Live Server.
